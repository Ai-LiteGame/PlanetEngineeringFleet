# 《星球工程车队》设计规格

日期：2026-09-03

## 1. 产品目标

制作一款适合幼儿园大班儿童（约 5–6 岁）的触屏优先网页小游戏。孩子通过驾驶工程车建设星球设施，在一个 6–8 分钟的短回合中练习：

- 识别和理解常用汉字；
- 听懂并跟说基础英语；
- 训练 10 以内数量、比较、规律和空间思维。

游戏可在平板和电脑浏览器运行，无需账号和联网服务。首版是一条完整、可重复游玩的“修建彩虹桥”任务线。

## 2. 设计原则

1. 工程车是学习动作的一部分，不是答题后的装饰奖励。
2. 每个学科连续练习约 2 分钟，再进入下一学科，最后进行一次综合提取。
3. 儿童不会因答错、语音识别或操作速度受到惩罚。
4. 页面指令短、按钮大、支持重复朗读，不要求儿童独立阅读说明文字。
5. 每次只引入 2–3 个新知识点，旧知识在后续回合间隔复现。
6. 不设置广告、排行榜、金币商店、连续登录奖励或无限游戏循环。

## 3. 核心体验

### 3.1 启动页

首屏直接展示星球工地和“开始施工”按钮。孩子点击后听到任务：“工程队，去为绿芽星修一座彩虹桥吧！”

成人设置入口以齿轮图标放在角落，需要长按两秒进入，避免儿童误触。首版设置仅包含音量、重置进度和学习记录。

### 3.2 一局流程

1. **挖掘机：汉字施工牌**，约 2 分钟。
2. **搅拌车：英语补给站**，约 2 分钟。
3. **吊车：数学吊装区**，约 2 分钟。
4. **翻斗车：综合配送**，约 1 分钟。
5. 展示建成的彩虹桥、获得的三颗能力星和本局学习摘要。

每站包含三道题。题目从对应题库轮换，一局共十二道题。首局优先使用教学题，重玩时轮换干扰项和顺序。

## 4. 学习内容与交互

### 4.1 汉字站：挖掘机

题型：听字音，在三个施工牌中选择目标汉字。孩子点击施工牌后，挖掘机移动并挖出材料。

首版字库：`山、水、火、木、土、路、桥、车、门、人、上、下`。

题目样例：

- “请挖出写着‘桥’的石头。”选项：桥、路、河。
- “找到‘车’。”选项：东、车、门。
- “哪个字是‘上’？”选项：下、上、土。

首次答错时重新朗读，并让正确施工牌轻微跳动。第二次答错时高亮目标字并朗读，不自动跳题。选择正确后，朗读汉字和一个短词组，例如“桥，彩虹桥”。

### 4.2 英语站：搅拌车

题型：听英文、跟说、看图确认。游戏使用浏览器语音合成播放标准示范，但不依赖语音识别判定儿童发音。

首版词汇：`go, stop, car, red, blue, yellow, one, two, three, big, small, help`。

每题流程：

1. 播放英文，例如 “Three blocks”。
2. 孩子点击麦克风按钮后跟说，按钮显示三秒呼吸动画；游戏不录音、不上传音频。
3. 孩子在三幅图中选择含义，例如选择三块砖。
4. 选择正确后再播放英文，并给出简短中文含义。

未获得麦克风权限不影响游戏，因为首版不采集音频。麦克风按钮仅承担跟读节奏提示，旁边始终提供重复播放按钮。

### 4.3 数学站：吊车

题型覆盖数量、比较、规律和空间关系。孩子点击或拖动材料，吊车同步搬运。

首版题型：

- 计数：按订单装入 1–10 块材料；
- 比较：选择材料更多或更少的车厢；
- 规律：补全 AB、AAB 或颜色/形状规律；
- 空间：选择能填入桥面缺口的形状或方向。

首版不使用倒计时。错误材料回到原位，并提供视觉线索；正确后吊车完成一次明确的吊装动画。

### 4.4 综合站：翻斗车

综合任务只调用本局刚练过的内容，不引入新知识。示例：“把 3 块黄色桥砖送到‘桥’字施工牌旁。”孩子需要选择数量、颜色和汉字目标，然后翻斗车完成配送。

综合任务完成后，桥梁最后一段落位，车辆一起亮灯庆祝。

## 5. 难度与复习

每个知识项目在本地记录独立表现：独立答对、提示后答对、未完成。系统不向儿童显示分数。

- 连续三次独立答对：该项目进入“已掌握”，后续降低出现频率并加入更相近的干扰项。
- 连续两次需要提示：下一题降低难度，例如减少一个干扰项、增加图片或数量点阵。
- 已掌握项目在后续第 2、4、7 局安排复现；答错后恢复正常频率。
- 单局仍固定为十二题，不因水平提高而延长。

首版只实现本地、自适应的题目选择，不实现云端课程、教师班级或多人数据。

## 6. 反馈与奖励

- 答对：车辆立即动作，材料进入工程，播放短促正向音效。
- 答错：不扣星、不显示红叉或失败文字；以再次朗读、动作提示和高亮逐级帮助。
- 每完成一个学科站获得对应能力星：汉字星、英语星、数学星。
- 三颗星用于展示本局完成情况，不作为消费货币。
- 每局完成一段永久工程进度；首版包含桥墩、桥面、灯光三个可见阶段，第三局后保持完整桥梁并切换天气和材料配色供重复游玩。

## 7. 界面与视觉

视觉主题为明亮的外星工地，使用蓝、绿色环境，黄色工程车和红色重点提示，避免单一色系。场景中包含可辨认的挖掘机、搅拌车、吊车和翻斗车。

- 触控目标最小 56 × 56 CSS 像素；主要答案区域更大。
- 正文和题目不随视口宽度缩放，窄屏通过换行和重排适配。
- 支持 320px 宽手机，但主要验收设备为横屏平板和桌面浏览器。
- 无文字覆盖、横向滚动或依赖悬停的操作。
- 关键按钮同时使用图标和简短文字；声音按钮提供可访问名称。
- 动画尊重 `prefers-reduced-motion`，关闭后保留状态变化而取消位移和弹跳。

首版视觉资产使用代码绘制的场景、CSS 形状和工程车图形，避免外部资源失败。音频使用 Web Speech API 与程序化短音效，不加载远程媒体。

## 8. 技术方案

项目为空目录，采用无构建依赖的静态 Web 应用：

- `index.html`：应用入口和语义结构；
- `styles.css`：响应式视觉、车辆和场景动画；
- `src/content.js`：汉字、英语、数学题库；
- `src/game.js`：状态机、出题、自适应记录和本地持久化；
- `src/audio.js`：语音合成与程序化音效；
- `tests/`：使用 Node 内置测试运行器验证纯逻辑。

核心状态机为：`intro → chinese → english → math → mixed → complete`。界面层订阅状态并渲染当前关卡，不将题目规则散落在 DOM 事件中。

进度以版本化 JSON 存入 `localStorage`。数据损坏或版本不兼容时恢复为初始状态，不阻塞开局。

## 9. 错误与降级

- 浏览器不支持语音合成：继续显示英文文本与发音拆分，游戏保持可玩。
- 音频上下文被浏览器阻止：首次用户点击后再初始化音效。
- 本地存储不可用：本次会话继续运行，仅不保留跨会话进度。
- 刷新页面：恢复到本局当前学科的第一题，避免恢复到动画中间状态。
- 连续快速点击：当前题锁定到反馈结束，防止重复计分和跨题。

## 10. 验收标准

1. 从启动页到完成页可完整玩通一局，涵盖四个站点和十二道题。
2. 四类工程车均参与可见、与学习含义一致的互动。
3. 汉字站具备朗读、三选一、两级提示和正确反馈。
4. 英语站具备示范朗读、三秒跟读节奏和看图确认，不采集音频。
5. 数学站至少覆盖计数、规律、比较和空间题中的三类。
6. 综合站同时使用本局的汉字、英语或数学内容中的至少两类信息。
7. 答错不扣分；题目经提示后仍可完成。
8. 完成记录和工程进度能写入本地并在刷新后保留。
9. 在 1280 × 800、1024 × 768、390 × 844 三种视口下无内容重叠、裁切和横向滚动。
10. 主要流程支持鼠标、触控和键盘；重复朗读按钮具有可访问名称。
11. 逻辑测试覆盖状态转换、提示升级、自适应难度、题目选择和持久化恢复。
12. 游戏无需网络连接即可运行，浏览器不支持语音时仍可完成。

## 11. 首版范围外

- 真实语音识别和发音评分；
- 教师后台、账号、云同步和跨设备进度；
- 自由驾驶的开放世界；
- 多名儿童档案；
- 内购、广告、排行榜和社交分享；
- 超过一条主任务线的完整内容制作。
