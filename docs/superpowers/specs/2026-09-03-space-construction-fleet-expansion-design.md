# 《星球工程车队》长期课程扩展设计规格

日期：2026-09-03

## 1. 产品目标

把现有的 6–8 分钟单任务小游戏扩展为一套可持续约 15–18 个月的工程车学习游戏，覆盖上海幼儿园大班、幼小衔接和小学一年级阶段。

产品采用“双轨”设计：儿童看到的是生动的工程建设任务；课程底层同时维护大班适龄的基础能力线和一年级学科拓展线。游戏不照搬课本、不设置考试式刷题，但要让儿童逐步具备真实入学和一年级学习所需的识字、英语听说与数学能力。

运行形式保持为触屏优先的静态 Web 应用，支持平板、电脑和手机，无账号、无广告、无网络依赖，学习数据只保存在当前设备。

## 2. 目标用户与设计边界

- 主要用户：幼儿园大班儿童，约 5–6 岁；课程可延续到小学一年级结束。
- 使用方式：儿童可独立操作，成人可查看课程表与学习记录。
- 单节时长：8–12 分钟，每周建议 4 节。
- 完整规模：90 个工程项目，每个项目包含 3 节微课程，共 270 节。
- 游戏不教授汉字书写，不进行英语拼写测验，不使用语音识别给发音打分。
- 不通过排行榜、连续登录、金币商店、倒计时或失败惩罚制造压力。

“已看过”“已练习”和“已掌握”必须分别记录。打开课程或看完演示不等于掌握。

## 3. 课程容量与三阶段结构

### 3.1 总体学习目标

- 汉字：内容库包含 700 个去重识读字，其中 300 个高频核心字要求形成稳定识认；配套常用词语、短句和简短阅读。
- 英语：内容库包含 300 个去重听说词汇、100 个生活交流句型；目标是听懂、跟说并在情境中作出正确回应。
- 数学：从 10 以内数感与加减，逐步扩展到 20 以内加减、100 以内数概念及一年级基础计算；同时覆盖分类、比较、规律、空间、测量、钟表、钱币和简单应用题。

总量是内容覆盖范围，不表示所有项目都要求在大班阶段掌握。

### 3.2 阶段分层

| 阶段 | 工程项目 | 微课程 | 累计汉字 | 累计英语词汇 | 累计句型 | 数学上限 |
| --- | ---: | ---: | ---: | ---: | ---: | --- |
| 大班基础 | 1–30 | 1–90 | 200 | 90 | 30 | 10 以内数感与加减，初识 20 |
| 幼小衔接 | 31–60 | 91–180 | 450 | 190 | 65 | 20 以内加减及生活数学 |
| 一年级拓展 | 61–90 | 181–270 | 700 | 300 | 100 | 100 以内数概念与基础加减 |

成人可在课程表中预览三个阶段。儿童默认按顺序推进，但系统允许已具备基础的儿童通过复习型检测加快前段进度，不用重复完成大量已掌握内容。

### 3.3 单节内容密度

每节只引入少量新内容：

- 2–4 个新汉字；
- 1–2 个新英语词汇；
- 每 2–3 节引入 1 个交流句型；
- 1 个数学小目标。

一节约 12 个互动，采用“同科短段 + 综合应用”的结构：

1. 2 个旧知识热身；
2. 3 个汉字互动；
3. 3 个英语听说互动；
4. 3 个数学互动；
5. 1 个综合工程任务。

同一知识会在首次学习后约 1 天、3 天、7 天、14 天和 30 天再次出现。系统以完成节次作为离线近似间隔；有真实日期时同时参考日期。

## 4. 世界、项目与视觉体验

### 4.1 六大工程区域

90 个项目平均分布在六个区域，每区 15 个项目：

1. 阳光工程镇：修路、建房、安装路灯；
2. 森林救援谷：清障、搭桥、救援动物；
3. 港口物流岛：装货、分类、安排运输；
4. 海底隧道城：铺管、接电、修建观测站；
5. 冰雪机场：除雪、导航、搭建机库；
6. 未来上海城：修地铁、建高楼、规划交通和滨水设施。

每个项目有三节：勘察与学习、施工与应用、验收与间隔复习。第三节完成后，场景发生永久可见变化。

### 4.2 车辆阵容

核心车辆包括挖掘机、推土机、吊车、搅拌车、翻斗车、压路机、叉车、消防工程车、除雪车和隧道钻机。每辆车有与任务含义一致的动作，而不是答题后的装饰：挖掘、推土、起吊、搅拌、卸料、压路、装卸、喷水、除雪和钻进。

车辆部件分层绘制，以便车轮、机械臂、吊钩、料斗和灯光分别动画。工程完成时，路面、桥梁、建筑或设施真实出现在场景中。

### 4.3 视觉语言

- 采用清晰的二维绘本式工程世界，粗轮廓、可辨认机械结构、明亮的自然色与工程警示色。
- 主场景全宽展开，不放入装饰卡片；学习控件位于场景下方的稳定操作带。
- 六个区域有明显环境差异，不使用单一蓝色或紫色调覆盖所有页面。
- 车辆动作伴随适量粒子、材料移动、灯光和短音效；不使用持续闪烁和大幅抖动。
- 支持 `prefers-reduced-motion`，关闭运动后仍显示明确的施工前后状态。
- 儿童界面只显示任务所需的短指令；课程说明、统计和筛选只出现在成人区域。

## 5. 核心页面与导航

### 5.1 工程世界地图

启动后直接进入工程地图。地图显示六个区域和当前工程车位置，已完成道路会亮起，当前工地有车辆作业动画，未开放区域可预览但不能误触进入。

顶部只保留当前区域、项目进度、声音和成人入口。主操作是“继续施工”。儿童也可点击已完成项目重新挑战。

### 5.2 课程内体验

课程保持一个明确任务，不展示学科分数。每段开始时由工程队长用一句话说明目标；回答正确立即触发对应施工动作，随后进入下一互动。

答错不显示红叉、不扣奖励：

1. 第一次：重放语音并给出动作方向；
2. 第二次：减少干扰或突出关键特征；
3. 第三次及以后：演示答案，让儿童再完成一次操作。

英语跟说只提供示范、三秒表达时间和情境选择，不录音。句型任务要求在角色交流中使用，例如请求帮助、确认数量、描述位置和表达需要。

### 5.3 儿童荣誉与车库

- 每个项目完成后获得一枚项目徽章，共 90 枚；徽章奖励坚持完成，不与答题正确率绑定。
- 每个区域根据独立完成和间隔复习情况获得铜、银、金三档工程奖章。
- 车辆外观随项目推进获得安全帽、工作灯、车身贴纸和工具部件，只用于展示，不形成货币或商店。
- 完成三个课程阶段分别获得“大班小工程师”“幼小衔接工程师”“星球总工程师”荣誉。

## 6. 课程目录与学习记录

### 6.1 儿童课程地图

儿童端使用项目地图而不是表格。项目节点显示未开放、可学习、施工中、待复习和已完成状态。已完成课程可直接重玩，但不会因重玩重复发放徽章。

### 6.2 成人课程表

成人入口进入独立的课程表视图，可按阶段、区域、科目和状态筛选。每节显示：

- 课程编号、项目名称与课次；
- 本节汉字、英语词汇、交流句型和数学目标；
- 预计时长；
- 首次查看时间、完成次数、最近学习时间；
- 使用提示次数；
- 当前学习状态。

学习状态定义：

| 状态 | 判定 |
| --- | --- |
| 未开始 | 从未进入该课程 |
| 已看过 | 已完成本节新知识演示，但未完成整节互动 |
| 已练习 | 至少完整完成一次课程 |
| 待复习 | 到达复习时间，或近期需要多次提示 |
| 已掌握 | 至少 3 次跨节独立答对，并通过一次间隔复习 |

成人可查看整体完成度、三科覆盖量、待复习项目和最近学习记录。导出功能生成 JSON 文件，包含课程状态和技能记录；不包含录音，因为应用从不采集录音。

## 7. 自适应学习与出题

课程清单固定，具体互动从模板生成。内容数据与呈现模板分离：一个汉字或词汇可以出现在辨认、配对、听音选择、情境理解和综合配送等不同题型中。

出题优先级依次为：

1. 当前课程指定的新内容；
2. 到期复习内容；
3. 近期需要提示的薄弱内容；
4. 已掌握内容的低频维护。

每节必须保持新旧内容比例约 1:2。综合任务只组合本节已学习或已复习的内容，不在最后一步突然引入新知识。

“已掌握”按具体技能记录，而不是按整节课一次性标记。单个项目答错后不会清空全部历史，但会重新进入待复习队列。

## 8. 技术架构

继续使用原生 HTML、CSS 和 JavaScript ES Modules，不引入运行时框架。为了控制 270 节课程和大量内容，现有模块拆分为：

- `src/curriculum/regions.js`：六个区域和 90 个项目元数据；
- `src/curriculum/lessons.js`：270 节课程目标与内容映射；
- `src/curriculum/chinese.js`：汉字、词语、例句和辨识特征；
- `src/curriculum/english.js`：词汇、句型、中文语义和语音文本；
- `src/curriculum/math.js`：数学技能阶梯和生成参数；
- `src/question-factories.js`：从课程内容生成不同交互题；
- `src/game-core.js`：课程状态机、答题状态和完成流程；
- `src/mastery.js`：技能掌握度、复习到期与自适应选择；
- `src/storage.js`：版本化进度、迁移、导出与恢复；
- `src/views/`：地图、课程、完成页、车库、课程表和成人统计；
- `src/app.js`：导航、事件协调与浏览器 API 适配；
- `assets/`：分层车辆、区域场景与音效资源。

内容模块必须可被 Node 测试直接导入。页面不直接判断课程规则，DOM 事件只向核心状态机提交动作。

## 9. 状态与数据流

持久化数据升级为版本 2，核心结构包含：

```js
{
  version: 2,
  currentLessonId: "lesson-001",
  lessons: {
    "lesson-001": {
      viewedAt: 1788364800000,
      completedCount: 0,
      lastCompletedAt: null,
      status: "viewed"
    }
  },
  skills: {
    "zh:桥": {
      exposures: 1,
      independentCorrect: 0,
      assistedCorrect: 0,
      nextReviewAt: null,
      status: "practicing"
    }
  },
  honors: [],
  vehicleUpgrades: [],
  settings: { soundEnabled: true }
}
```

版本 1 进度迁移时保留声音设置、已完成局数和已有技能记录；这些记录映射为早期课程的练习证据。迁移失败时先保留原始字符串的内存副本，再使用空的版本 2 数据启动，不能阻塞游戏。

活动课程快照记录课程编号、互动编号和确定性随机种子。刷新后恢复到当前互动的稳定初始状态，不恢复动画中间帧，也不重复发放奖励。

## 10. 错误处理与降级

- 语音合成不可用：显示英文和中文情境图，所有课程仍可完成。
- 程序化音效不可用或被浏览器阻止：静默继续，首次用户操作后再尝试初始化。
- Local Storage 不可用：当前会话继续；成人页面明确显示“本次记录不会保存”。
- 单条课程或内容配置无效：开发测试必须失败；生产运行跳过该条并回到地图，不显示空白页。
- 活动快照损坏：回到对应课程开头，已持久化的完成记录不受影响。
- 连续点击和页面重复事件：提交后立即锁定当前互动，奖励写入使用幂等标识。
- 全部课程模块和资源随静态应用一同交付，不在游玩时临时下载远程内容；资源加载异常时回到地图并提供重试入口。

## 11. 测试与验收

### 11.1 数据完整性

1. 正好生成 6 个区域、90 个项目和 270 节唯一课程。
2. 课程累计覆盖正好 700 个去重汉字、300 个去重英语词汇和 100 个去重句型。
3. 每节的新内容数量和 12 个互动结构符合限制。
4. 所有课程引用的技能、选项、语音文本和题型模板存在。
5. 三阶段数学技能只引用该阶段允许的数值范围。

### 11.2 学习逻辑

1. 首次演示只记录“已看过”，完整完成才记录“已练习”。
2. 掌握必须包含跨节独立答对和间隔复习，不能由一次课程直接获得。
3. 到期内容、薄弱内容和已掌握内容按设计权重进入课程。
4. 提示升级、重复提交保护、奖励幂等和中途恢复均有单元测试。
5. 版本 1 数据可迁移，损坏数据可恢复，存储异常不影响当前课程。

### 11.3 浏览器体验

1. 从地图进入课程、完成项目、获得徽章、打开下一项目的主流程可完整跑通。
2. 课程表正确显示并筛选五种状态；重玩不会重复发奖。
3. 每类车辆至少有一个与任务匹配的可见动作；六个区域视觉明显不同。
4. 在 1280×800、1024×768、390×844 视口无重叠、横向溢出或不可达控件。
5. 触控目标至少 56×56 CSS 像素，键盘焦点可见，关闭动画后功能完整。
6. 禁用网络、语音合成和 Local Storage 后仍能进入并完成课程。

## 12. 本次扩展不包含

- 云同步、账号、多儿童档案和教师班级后台；
- 麦克风录音、语音识别或自动发音评分；
- 汉字描红和书写评分；
- 排行榜、社交分享、广告、内购和虚拟货币；
- 自由驾驶的开放世界或需要物理引擎的车辆模拟。

这些边界保证第一轮扩展能形成完整、可验证、可持续学习的单机版本。
