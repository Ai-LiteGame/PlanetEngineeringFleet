# 星球工程车队

一款面向幼儿园大班到小学一年级儿童的触屏学习游戏。孩子驾驶十类工程车完成六个区域的建设任务，在工程情境中练习汉字识读、英语听说和数学思维；成人可查看课程表、学习状态和长期进度。

## 开始游戏

项目使用原生 HTML、CSS 和 JavaScript，没有第三方运行依赖。需要 Node.js 18 或更高版本：

```bash
npm start
```

打开 [http://localhost:4173](http://localhost:4173)。停止服务按 `Ctrl+C`。

运行全部自动测试：

```bash
npm test
```

测试覆盖课程内容完整性、游戏状态转换、提示升级、重复提交保护、自适应掌握度、间隔复习、刷新恢复、幂等奖励、本地资源引用和存储降级。

## 课程结构

完整课程包含 6 个区域、90 个工程项目和 270 节微课程。每个项目依次包含“勘察与学习”“施工与应用”“验收与间隔复习”三节，单节约 12 个互动，预计 8–12 分钟。

| 阶段 | 项目 | 课程 | 累计汉字 | 累计英语词汇 | 累计句型 | 数学范围 |
| --- | ---: | ---: | ---: | ---: | ---: | --- |
| 大班基础 | 1–30 | 1–90 | 200 | 90 | 30 | 10 以内数感与加减，初识 20 |
| 幼小衔接 | 31–60 | 91–180 | 450 | 190 | 65 | 20 以内加减与生活数学 |
| 一年级拓展 | 61–90 | 181–270 | 700 | 300 | 100 | 100 以内数概念与基础加减 |

内容库总计正好 700 个去重汉字、300 个去重英语词汇、100 个去重交流句型，并覆盖 33 个数学技能（分属 11 类数学能力）。新内容只在前两类课程引入，验收课只复习。阶段 2 和阶段 3 各有 10 节引入 5 个新汉字，其余引入课为 3–4 个。

每节由 2 个旧知识热身、3 个汉字互动、3 个英语互动、3 个数学互动和 1 个综合任务组成。学习记录中每科有足够的已见技能并有两个热身技能时，新旧内容约为 1:2；冷启动或同科历史不足时使用当前课程内容补足，不把未见内容标为复习。

答错不会扣分或跳题。提示逐级增加，第三次会演示正确选项，儿童仍需亲自选择才能继续。英语跟说提供示范和三秒表达时间，但不录音、不评分。

## 学习记录与导出

进度只写入当前浏览器的 Local Storage，包括五种课程状态、技能练习证据、项目徽章、区域奖章、车辆升级和声音设置。未完成课程另存一个版本 2 快照：课程编号、互动位置、经过清理的已完成答案及课程生成时间戳；刷新后可稳定恢复，不保存动画中间帧。

成人入口中的“课程表”可按阶段、科目、区域和状态查看 270 节课程。“下载 JSON”导出课程、技能和荣誉记录；导出文件不包含活动快照、设备信息或音频。“设置”页可用两次确认清除本游戏的四个存储键，不影响同站点的其他数据。

Local Storage 不可用或访问被浏览器阻止时，当前会话仍可继续，地图与成人课程表会显示“本次记录不会保存”。语音合成和程序化音效不可用时，所有题目仍有可见文字与图形提示。

## 浏览器与离线

支持当前版本的 Chrome、Edge、Safari 和 Firefox，以及基于这些浏览器的平板与手机浏览器。界面适配 1280×800、1024×768 和 390×844 等常见视口，主要触控目标至少为 56×56 CSS 像素，并支持键盘焦点与 `prefers-reduced-motion`。

所有课程、代码、SVG 场景和车辆资源都随项目本地提供，不使用 CDN 或远程运行资源。页面完成首次在线加载并缓存资源后，即使网络断开，当前课程也可继续运行；首次打开或发布新版本后，仍需要连接到承载这些静态文件的服务器一次。

### PWA 打包与部署

为家庭或学校部署可安装的网页应用时运行：

```bash
npm run package:pwa
```

命令会生成可直接部署的目录 `dist/planet-engineering-fleet-pwa/` 和压缩包 `dist/planet-engineering-fleet-pwa.zip`。将目录中的全部内容上传到同一个静态站点目录，或先解压 ZIP 再上传；不要只上传 `index.html`，也不要改动文件名、相对路径或目录结构。正式站点必须通过 HTTPS 提供；`http://localhost` 仅用于本机开发和验收。部署在域名根目录或子目录均可，但必须保留包内的相对路径。

这是浏览器提供的 PWA 安装，不是 Android APK、macOS DMG 或 Windows EXE 原生安装包。先在目标设备上在线打开部署地址，等待页面完整显示，再按平台操作：

- **Android 手机和平板：**使用 Chrome 打开，点浏览器菜单中的“安装应用”或“添加到主屏幕”，再确认安装。
- **Windows 和 macOS：**使用 Chrome 或 Edge 打开，点地址栏的安装图标；图标未显示时，从浏览器菜单选择“安装星球工程车队”。
- **iPhone 和 iPad：**使用 Safari 打开，点“分享”，再点“添加到主屏幕”并确认。

安装后仍应从同一 HTTPS 地址更新内容。学习进度只保存在当前设备、当前浏览器和当前站点地址的 Local Storage 中，学习记录不会跨设备同步。卸载 PWA 不一定会删除浏览器站点数据；清除该站点数据会永久删除本机学习记录，重新安装不会恢复，操作前可在成人入口下载 JSON 备份。

## 隐私边界

- 不需要账号，不含广告、内购、排行榜或云同步。
- 不申请麦克风权限，不采集、保存或上传录音，不做发音评分。
- 不向外部服务发送学习记录、设备信息或分析事件。
- 不包含教师班级后台、多人档案、汉字书写评分或开放世界驾驶。
