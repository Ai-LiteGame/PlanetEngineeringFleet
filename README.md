# 星球工程车队

一款面向幼儿园大班儿童（约 5–6 岁）的触屏网页小游戏。孩子通过操作挖掘机、搅拌车、吊车和翻斗车修建彩虹桥，在一局中分段练习汉字、英语跟说和数学思维，最后完成综合配送任务。

## 开始游戏

项目没有第三方运行依赖。在项目目录执行：

```bash
npm start
```

然后打开 [http://localhost:4173](http://localhost:4173)。平板和电脑浏览器均可使用，推荐横屏平板。

## 运行测试

需要 Node.js 18 或更高版本：

```bash
npm test
```

测试覆盖游戏状态转换、提示升级、重复提交保护、自适应掌握度、间隔复习权重、刷新快照和损坏存储恢复。

## 学习结构

每局固定十二题，预计 6–8 分钟：

1. 挖掘机识别常用汉字；
2. 搅拌车示范英语并留出三秒跟说时间；
3. 吊车完成数量、比较、规律和空间题；
4. 翻斗车在综合任务中调用本局内容。

答错不会扣分或跳题。第一次答错会获得动作提示，第二次会看到明确线索和高亮答案。

## 隐私与离线能力

- 游戏不需要账号，不发送网络请求，也不加载远程资源；
- 英语跟说不会申请麦克风权限，不录音、不上传、不进行发音评分；
- 学习记录只保存在当前浏览器的 Local Storage；
- 浏览器不支持语音合成或声音被关闭时，所有关卡仍可通过文字和图形完成。

## 首版范围

首版包含一条可重复游玩的“修建彩虹桥”任务线、四个学习站、每站六题题库、三阶段桥梁进度和成人设置。教师后台、云同步、多人档案、开放世界驾驶、广告和付费系统不在首版范围内。
